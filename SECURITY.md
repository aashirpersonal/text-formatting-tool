# Security policy

## Supported versions

Security fixes are accepted against the active `v2-rebuild` / future v2 release line. Legacy Create React App v1 (`legacy-v1` tag) is historical and is not supported for redeployment.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

If this repository enables GitHub Security Advisories, use **Report a vulnerability** on the Security tab to request a private advisory:

https://github.com/aashirpersonal/text-formatting-tool/security/advisories/new

If that form is unavailable, open a minimal public issue titled `Request private security contact` without including exploit details, and wait for a maintainer to share a private channel.

## Scope notes

- Do not submit API keys or private document contents in reports.
- Model-generated JavaScript execution is explicitly forbidden in v2 architecture; reports that demonstrate regressions of that boundary are high priority.
